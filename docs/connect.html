Connect your AI

One private Daybook, across ChatGPT, Claude, Gemini, Cursor, Claude Code and Codex. Choose an assistant and follow its connection steps. You'll approve access in the assistant.

Find this in your Daybook app after setup. Don't enter a password or token here. The address stays in your browser.

Claude

Add a custom web connector called Daybook. Claude will ask you to sign in.

Open Claude connectors ↗
  1. Choose Add → Custom → Web.
  2. Name it Daybook and paste your copied address.
  3. Approve the connection and sign in.

ChatGPT

Create a personal plugin with your Daybook MCP address and OAuth authentication. The ChatGPT interface requires you to approve the plugin.

Open ChatGPT ↗
  1. Open Plugins → + → Add custom MCP server.
  2. Paste your address and select OAuth.
  3. Create as a plugin, approve sign-in, and install it.

Gemini

For eligible personal Google accounts in the US with Keep Activity enabled. Connect from Gemini web first, then use it on mobile.

Open Gemini ↗
  1. Open Settings → Connected Apps (sometimes under Personal Intelligence).
  2. Under Custom apps, select Add a custom app and paste your copied Daybook address.
  3. Complete authorization, then ask Gemini to list your Daybook notes.

Cursor

Install your Daybook server in Cursor with its official MCP install link. Cursor will ask you to confirm and authenticate.

Claude Code

In a terminal where Claude Code is installed, run this once on each computer. --scope user makes Daybook available in every project.

claude mcp add --transport http --scope user daybook YOUR_DAYBOOK_URL

  1. Start claude, type /mcp, pick daybook and choose Authenticate.
  2. Your browser asks for your Daybook password and notes the request redirects to your local computer. That's expected; choose Allow.

Codex CLI

In a terminal where Codex is installed, run this once on each computer, then sign in.

codex mcp add daybook --url YOUR_DAYBOOK_URL

  1. Sign in: codex mcp login daybook
  2. Your browser asks for your Daybook password and notes the request redirects to your local computer. That's expected; choose Allow.

Test your connection

Once connected, ask your assistant: “List my latest Daybook notes.” If it can retrieve them, you're ready.
