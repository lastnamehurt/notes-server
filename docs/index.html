Three simple steps

Yours from day one.

Create accounts

You'll need free GitHub and Cloudflare accounts to store and run your private Daybook.

Deploy your Daybook

Make up a password, tap Deploy to Cloudflare in the guide, and paste the password when Cloudflare asks.

Connect and capture

Finish GitHub authorization in the app, then optionally connect an AI assistant and add Daybook to your home screen.

Privacy, without mystery

Your notes aren't stored on our website.

Each person runs their own Cloudflare Worker with notes saved as plain-text Markdown in their own private GitHub repository. Your GitHub and Cloudflare accounts control access. This is not end-to-end encryption: your Worker and authorized AI integrations can read notes to provide features. The public landing page does not host your notes.
